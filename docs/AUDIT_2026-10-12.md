## Confirmed source defects and branch repairs

1. `init3D()` calls undefined `block()` while constructing apartment targets.
   Replaced with the existing `addBox()` helper. This fatal error occurs after
   renderer creation and is separate from the browser's WebGL failure.
2. Wheel input moves an orthographic camera without changing its projection.
   Update `camera.zoom` and its projection matrix when wheel input changes distance.
3. Camera presets retain a selected apartment's target. Reset target and zoom
   when changing presets.
4. Viewport fit uses `Math.max`, cropping one dimension. Use `Math.min` to
   preserve the full nominal scene bounds in narrow viewports.
5. Selection did not immediately refresh the selected-unit highlight. Refresh
   colors after selection; reject unknown unit IDs.
6. Add touch gesture ownership, pointer-cancel cleanup, visible focus outlines,
   bounded legend width, and a label disclosing schematic unit locations.

## Architectural findings (not repaired in this checkpoint)

- `assets/alterra-building.gltf` is unused. GLTFLoader is loaded but never called.
  Retain the legacy asset until a verified replacement is ready.
- Current shell is a single extruded polygon, but source pixels are scaled by
  `.24` horizontally and `.105` vertically. This changes sketch aspect ratio
  by approximately 2.29. Re-trace the recovered sketch with uniform scaling;
  do not interpret its freehand proportions as surveyed dimensions.
- Materials are flat colors without brick/siding textures. Window groups and
  balconies are generated using modulo counters rather than reference annotations.
- Only four roof equipment groups are generated; the reference shows many more.
- Unit targets use a rectangular grid, widths 6.9 and spacing 2.6, so targets
  overlap and are not tied to verified apartment locations or the footprint.
- Current lighting uses hemisphere intensity 2 plus directional intensity 1,
  without an explicit output color/tone-mapping setup. Material brightness needs
  visual calibration in a working renderer.
- Extra roof ShapeGeometry duplicates the shell's top cap at a small offset.
  Investigate roof topology and normals with the replacement mesh; the supplied
  rejected screenshot alone does not prove its precise defect is in current main.
